# Futbô

Quero um app que consiga fazer a leitura e analise dos ultimos jogos de um time especificado pelo cliente e que em seguida ele ofereça estatisticas claras sobre oque pode ser colocada em possiveis apostas, como taxa de escanteios, gols, cartoes e porcentagem de ganhos

This project was built with [Lovable](https://lovable.dev).
